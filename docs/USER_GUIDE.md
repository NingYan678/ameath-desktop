# 爱弥斯桌宠使用说明

**适用版本：1.1.0**

这是一份给普通用户的安装和使用说明。不需要了解 Hermes、编程或命令行；按照“第一次启动”一节操作，就可以开始使用。

## 一句话了解爱弥斯

爱弥斯是桌面上的小伙伴。它负责桌宠画面、动画、聊天输入和主动互动；回答问题的 AI 引擎叫 **Hermes**。

如果你以前没有用过 Hermes，不需要单独安装或学习它。第一次启动爱弥斯时，选择“独立爱弥斯 Hermes（内置模式）”，跟随向导连接一个 AI 模型服务即可。

## 你需要准备什么

| 使用方式 | 适合谁 | 需要准备 |
| --- | --- | --- |
| 独立爱弥斯 Hermes（推荐新用户） | 没有安装过 Hermes 的用户 | 一个 AI 服务账号、模型名和 API Key。 |
| 独立爱弥斯 Hermes + Ollama | 希望在本机运行模型的用户 | 已安装并运行 Ollama，且至少下载了一个模型。 |
| 本机 Hermes（共享模式） | 已经在使用 Hermes 的用户 | 现有 Hermes 的安装位置和可用的后台服务。 |

AI 服务可能按服务商规则收费。API Key 是服务商提供的访问凭证，类似密码；请勿把它发给别人或公开到网上。

## 1. 下载与安装

1. 打开项目的 [GitHub Releases](https://github.com/NingYan678/ameath-desktop/releases) 页面。
2. 下载同一版本的安装包和 `.sha256` 校验文件，例如：
   - `Ameath-1.1.0-offline-setup.exe`
   - `Ameath-1.1.0-offline-setup.exe.sha256`
3. 双击安装包，按向导完成安装。默认位置是 `%LOCALAPPDATA%\Programs\Ameath`。
4. 安装完成后，从开始菜单或桌面快捷方式启动爱弥斯。

当前安装包没有 Windows 代码签名，系统可能显示“未知发布者”。请确认文件来自上述 GitHub Release；有条件时，可用校验文件核对 SHA-256。不要使用来历不明的转发安装包。

## 2. 第一次启动：按这 6 步完成

### 第一步：选择后端

首次启动会询问使用哪个 Hermes：

- **没有安装过 Hermes**：选择“独立爱弥斯 Hermes（内置模式）”。这是新用户的推荐选项。
- **已经安装并正在使用 Hermes**：选择“本机 Hermes（共享模式）”。爱弥斯会连接它，但不会修改它的全局模型、人格或工具设置。
- **暂时不想配置**：选择“暂不设置”。之后可从设置页重新选择，但在配置完成前无法正常聊天。

### 第二步：选择 AI 服务

独立模式会显示服务选项，例如 DeepSeek、OpenAI、OpenAI 兼容接口或本机 Ollama。选择你已有账号或已安装的服务。

### 第三步：填写连接信息

- **模型名**：服务商提供的具体模型标识，不能随意填写；
- **服务地址**：服务商 API 文档提供的网址；使用 Ollama 时通常是本机地址；
- **API Key**：云服务的访问凭证；本机 Ollama 通常不需要填写。

不知道这些信息时，请打开对应服务商的 API 文档或控制台，不要猜测。爱弥斯不会替你创建云服务账号或 API Key。

### 第四步：测试连接

点击“测试连接”。显示成功后再点击“完成并启动”。测试失败时，优先检查服务地址、模型名、API Key、网络连接，以及 Ollama 是否正在运行。

### 第五步：等待桌宠出现

首次启动可能需要几秒准备后台服务。看到桌宠后，单击它或打开聊天发送一条简单消息，例如“你好”。

### 第六步：确认托盘图标

爱弥斯会常驻 Windows 系统托盘。关闭窗口通常只是隐藏到托盘；需要完全退出时，请右键托盘图标，选择“退出爱弥斯”。

## 3. 日常操作

| 操作 | 作用 |
| --- | --- |
| 单击桌宠 | 显示一次短回应并播放动作。 |
| 双击桌宠 | 播放招呼动作并打开聊天。 |
| 鼠标悬停 | 触发探头或观察动作，不会反复刷文字。 |
| 拖动桌宠 | 移动桌宠；松开鼠标时显示着陆反馈。 |
| 右键桌宠 | 打开快捷菜单。 |
| 托盘单击/双击 | 显示或隐藏桌宠。 |
| 托盘“打开聊天” | 展开聊天并聚焦输入框。 |
| 托盘“让爱弥斯说句话” | 手动请求一次主动互动。 |
| 托盘“暂停动画” | 暂停非必要动画，不会断开 Hermes。 |
| 托盘“重新连接 Hermes” | 重新连接当前 AI 后台。 |
| 托盘“设置” | 打开所有桌宠、更新和隐私选项。 |
| 托盘“导出诊断包” | 在本机生成供排错使用的脱敏日志。 |
| 托盘“退出爱弥斯” | 完全退出程序。 |

### 聊天快捷键

- `Enter`：发送；
- `Shift+Enter`：换行；
- `Esc`：收起聊天；
- `Ctrl+,`：打开设置。

## 4. 主动互动与动作

爱弥斯默认会偶尔主动说一句话。默认最长间隔为 5 分钟，实际大约每 3–5 分钟出现一次；启动、点击桌宠、发消息或修改设置后会重新计时。

主动互动不是实时通知，也不是必须回复的任务。以下情况会暂时停止，而且恢复后不会补发积压内容：

- 主动互动被关闭；
- 勿扰模式或安静时段；
- 全屏应用或游戏模式；
- 聊天展开、拖动桌宠、等待回答或确认操作；
- Windows 锁屏、休眠或低功耗状态。

带问题的文案会显示“回应”按钮。点击后会打开聊天并保留问题；你的第一条回复会带上这条问题的上下文。忽略、取消或超时都不会受到责备，也不会降低熟悉度。

爱弥斯会在招呼、探头、思考、困倦、庆祝、重连和安静陪伴之间切换。熟悉度只会影响少量台词和动作组合，不显示等级，不会产生饥饿、健康、签到或失败惩罚。

语音和音乐不会因为普通主动互动自动播放；全身动画只用于少量特殊庆祝或音乐事件。

## 5. 设置说明

在托盘菜单选择“设置”。外观调整会即时预览，桌宠设置点击“保存桌宠设置”后生效。

### 外观

- **桌宠大小**：120–360 px；
- **聊天宽度和高度**：分别调整收起/展开后的窗口大小；
- **背景不透明度**：数值越低越透明；
- **文字大小**：80%–150%。

### 桌宠行为

- **动画速度**：调整动作播放速度；
- **自动收缩等待**：聊天无操作多久后收起；
- **始终置顶**：保持在普通窗口上方；
- **登录 Windows 时启动桌宠**：开机后自动启动；
- **关闭窗口时隐藏到系统托盘**：关闭按钮只隐藏，不退出；
- **允许爱弥斯主动陪伴**：打开或关闭自动主动互动；
- **最长互动间隔**：5–240 分钟；实际间隔为设置值的 60%–100%；
- **自动检测全屏应用**：游戏或全屏时减少干扰；
- **勿扰模式**：完全暂停主动互动；
- **安静时段**：设置不主动说话的时间，可跨午夜，例如 23:00–08:00；
- **减少动画**：只保留静态待机、拖动反馈、聊天和错误状态；
- **低功耗模式**：`auto` 自动判断，`on` 强制节能，`off` 不主动降帧。

### 更新选项

- **Hermes 官方更新**：检查背后的 AI 引擎更新；
- **Ameath 应用更新**：检查爱弥斯桌宠本身的新安装包。

两者互相独立，下载安装前都会要求确认，不会静默升级。

## 6. Hermes 更新是怎么回事

### 共享模式

爱弥斯只更新你选择的那份 Hermes，并且会先检查它是不是官方仓库、是否有未提交修改。工作区不干净或身份无法确认时会拒绝更新，以免覆盖你的实验内容。

共享 Hermes 可能还被其他渠道、任务或程序使用；更新时它们可能短暂重启。爱弥斯不会修改共享 Hermes 的全局模型、人格、工具或记忆。

### 内置模式

内置 Hermes 每个版本放在独立目录中，验证成功后才切换。更新失败会自动回到上一份可用版本，不会更新你电脑上的其他 Hermes，也不会删除用户设置、聊天记忆或凭据。

后台最多每天检查一次。离线检查失败不会弹出错误窗口，稍后会自动重试；同一个版本只提醒一次。更新时不要强制结束程序，等待完成或回滚即可。

## 7. 爱弥斯应用更新

爱弥斯应用只跟踪官方 GitHub Release。启动稳定一段时间后会自动检查，发现新版本只提醒你，不会自动下载或安装。

下载前请确认：

- 版本来自 `NingYan678/ameath-desktop` 的正式 Release；
- 安装包文件名与版本一致；
- 随附的 `.sha256` 校验值匹配；
- Windows 的未知发布者提示与未签名状态符合发布说明。

正在聊天、等待 Hermes 回答、授权或更新 Hermes 时，应用更新会延期。安装失败不会删除当前版本。

## 8. 隐私与安全记忆提示

爱弥斯不会读取屏幕内容、前台窗口标题、文件、日历或浏览器内容，也不会因为你忽略它而责备你。

“安全的兴趣、目标和话题提示”默认关闭。明确开启并同意后：

- Hermes 只能返回短文本提示，不会把原始长期记忆交给桌宠；
- 每 6 小时最多请求一次；
- 本地只保存提示的哈希和过期时间，不保存提示原文；
- 关闭开关或选择“清除爱弥斯学习提示”不会删除 Hermes 自己的长期记忆。

模型凭据按当前 Windows 用户加密保存。诊断包只在本机生成，日志会尽量脱敏；分享前仍请自己检查，不要把诊断包公开发布。

## 9. 备份与卸载

### 备份

关闭爱弥斯后，在文件资源管理器地址栏输入 `%LOCALAPPDATA%\Ameath`，复制整个文件夹即可备份设置、熟悉度、更新状态和内置运行时。

凭据受 Windows 用户和系统保护，复制到另一台电脑或另一个 Windows 账户后不一定能使用。不要把凭据文件发给别人。

### 卸载

卸载时可以选择：

- **保留个人数据**：以后重新安装时保留设置、熟悉度、凭据和 Hermes 更新槽；
- **删除个人数据**：删除爱弥斯保存的用户数据。选择前请确认已完成备份。

## 10. 常见问题

### 爱弥斯不会自动说话

先确认托盘菜单显示“主动互动：已开启”，再检查勿扰、安静时段、游戏/全屏、聊天展开、锁屏和休眠状态。默认需要等待约 3–5 分钟，也可以从托盘选择“让爱弥斯说句话”立即测试。

### 测试连接失败

检查模型名、服务地址和 API Key 是否来自服务商的官方说明。使用 Ollama 时确认 Ollama 正在运行且已经下载模型；使用云服务时确认网络正常、Key 尚未过期。

### 显示“Gateway 进程身份不匹配，已安全断开”

这是安全保护，表示发现的后台服务不是当前爱弥斯启动的那一份。关闭重复的 Hermes/Gateway 后，在设置里重新选择或检测 Hermes，再点击“重新连接 Hermes”。不要随意结束不确定的系统进程。

### Hermes 更新失败

打开错误提示中的日志位置，检查网络、Hermes 是否正在被其他程序使用，以及共享仓库是否有未提交修改。共享模式不要使用强制更新参数；内置模式会保留旧版本并自动回滚。

### 桌宠窗口不见了

先查看 Windows 系统托盘，右键爱弥斯选择“显示/隐藏”。如果刚拔掉显示器或改变了缩放比例，爱弥斯会尝试把窗口放回可见区域。

### 如何导出排错信息

右键托盘图标，选择“导出诊断包”，再把生成的文件提供给维护者。公开分享前请检查其中是否包含个人对话、服务地址或其他业务信息。

## 11. 术语小词典

| 术语 | 简单解释 |
| --- | --- |
| Hermes | 爱弥斯背后的 AI 引擎，负责理解消息和生成回答。 |
| Gateway | Hermes 的后台服务，爱弥斯通过它与 AI 引擎通信。 |
| 共享模式 | 使用电脑上已有的 Hermes。 |
| 内置模式 | 爱弥斯自己维护的一份 Hermes，与其他 Hermes 隔离。 |
| 模型服务 | 提供 AI 回答的服务，例如 DeepSeek、OpenAI 或 Ollama。 |
| 模型名 | 具体要使用的模型标识，按服务商说明填写。 |
| API Key | 云服务访问凭证，类似密码。 |
| 服务地址 | 模型服务的接口网址。 |
