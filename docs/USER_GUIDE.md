# 爱弥斯桌宠使用手册

本手册适用于爱弥斯（Ameath Desktop）1.1.0，面向第一次安装、日常使用、Hermes 连接与故障排查。爱弥斯负责桌面窗口、输入、动画和陪伴互动；模型、工具、任务和长期记忆由 Hermes Gateway 负责。

> **完全没用过 Hermes？先记住一句话：** Hermes 是爱弥斯背后的 AI 引擎，负责理解你的消息并生成回答。你不需要先单独学习或安装 Hermes；首次启动时选择“独立爱弥斯 Hermes”，跟着向导测试连接即可。

## 给完全新手的 5 分钟流程

如果你只想先把桌宠用起来，按下面顺序操作：

1. 安装并启动爱弥斯。
2. 首次选择后端时，**没有自己安装 Hermes 就选“独立爱弥斯 Hermes（内置模式）”**；只有已经在本机运行 Hermes、并且知道它的位置时，才选“本机 Hermes（共享模式）”。
3. 在模型配置向导中选择你使用的 AI 服务。例如 DeepSeek、OpenAI、兼容 OpenAI 接口的服务，或本机 Ollama。
4. 填写模型名和服务地址；云服务通常还需要 API Key。API Key 是服务商发给你的访问密码，不是爱弥斯生成的密码，也不要发给别人。
5. 点击“测试连接”。显示成功后点击“完成并启动”。如果失败，先检查服务地址、模型名、Key 是否填写正确，以及网络或本机 Ollama 是否正在运行。
6. 桌宠出现后，可以直接单击它、双击它，或从托盘选择“打开聊天”。

第一次使用不需要理解 Gateway、插件、运行时或 Git。它们是维护和更新时才会用到的技术名称；遇到这些词时，先按本手册的“故障排查”操作即可。

## 1. 快速开始

### 1.1 安装

1. 从项目的 [GitHub Releases](https://github.com/NingYan678/ameath-desktop/releases) 下载与版本号对应的 `Ameath-x.y.z-offline-setup.exe` 和 `.sha256` 文件。
2. （推荐）先校验 SHA-256。PowerShell 示例：

   ```powershell
   Get-FileHash .\Ameath-1.1.0-offline-setup.exe -Algorithm SHA256
   Get-Content .\Ameath-1.1.0-offline-setup.exe.sha256
   ```

   两行中的 64 位十六进制值必须一致。
3. 双击安装包，默认安装到 `%LOCALAPPDATA%\Programs\Ameath`。安装器只需要当前 Windows 用户权限。
4. 安装完成后启动爱弥斯。首次启动会打开后端选择或模型配置向导。

当前 1.1.0 安装包没有代码签名证书，Windows 可能显示“未知发布者”。这不等于文件损坏；请以 GitHub Release 页面和 SHA-256 为准。

### 1.2 首次配置

爱弥斯会先尝试发现本机 Hermes。你可以选择：

- **本机 Hermes（共享模式）**：连接你已有的 Hermes 安装。爱弥斯只安装或更新桌宠专属插件，不修改 Hermes 的全局模型、人格、工具或其他渠道设置。
- **独立爱弥斯 Hermes（内置模式）**：使用爱弥斯自己的隔离运行时和数据目录，不依赖或改动 `D:\hermes\hermes-agent`。
- **暂不设置**：稍后从设置页重新选择后端。

独立模式向导需要模型服务、模型名、服务地址和 API Key（Ollama 通常不需要 Key）。点击“测试连接”后再完成配置。凭据会按当前 Windows 用户加密保存，不写入桌宠文案或普通运行日志。

#### 怎么选择模型服务

| 你现在的情况 | 选择 | 需要准备什么 |
| --- | --- | --- |
| 没有 Hermes，也没有本地 AI 服务 | 独立爱弥斯 Hermes | 一个可用的云端 AI 服务账号、模型名和 API Key。 |
| 已经在电脑上运行 Ollama | 独立爱弥斯 Hermes | Ollama 已启动、模型已下载；通常不需要 API Key。 |
| 已经安装并使用 Hermes | 本机 Hermes（共享模式） | Hermes 的安装位置和正在运行/可启动的 Gateway。 |
| 只是想先看桌宠，不想配置 AI | 暂不设置 | 之后从设置页重新选择；没有 Gateway 时不能正常聊天。 |

**模型名和服务地址从哪里找？** 云服务的控制台或 API 文档会提供这两项；不要凭感觉填写。若使用 Ollama，先在本机安装并运行 Ollama，再在 Ollama 中下载至少一个模型。

## 2. 日常操作

| 操作 | 结果 |
| --- | --- |
| 单击桌宠 | 显示一次短回应并播放对应动作；每天最多 5 次会增加熟悉度，熟悉度不会因不使用而下降。 |
| 双击桌宠 | 播放招呼动作并展开聊天。 |
| 鼠标悬停 | 触发带冷却的探头或观察动作，不刷屏。 |
| 拖动桌宠 | 移动窗口；松开时显示一次着陆反馈。 |

| 托盘“让爱弥斯说句话” | 立即请求一次主动互动；仍会遵守忙碌、勿扰、全屏等保护条件。 |
| 托盘“暂停动画” | 暂停非必要动画，不退出 Gateway。 |
| 托盘“主动互动：已开启/已暂停” | 切换主动互动。 |

## 3. 聊天与主动互动

### 3.1 发送消息

在聊天输入框中输入内容：

- `Enter` 发送；
- `Shift+Enter` 换行；
- `Esc` 收起聊天；
- `Ctrl+,` 打开设置。

爱弥斯只显示和转发输入内容，具体回答由 Hermes 生成。等待回答、授权或确认时，不会触发新的主动互动。

### 3.2 主动说话为什么不是立刻出现

默认最长间隔是 5 分钟，实际会在最长间隔的 60%–100% 之间随机，也就是约 3–5 分钟。每次启动、点击桌宠、发送消息或修改设置后都会重新计时。

主动互动会在以下情况暂停，而且不会在恢复时补发积压消息：

- 关闭“允许爱弥斯主动陪伴”；
- 勿扰模式或安静时段；
- 真正的全屏应用或游戏模式；
- 聊天展开、拖动窗口、确认操作或 Gateway 忙碌；
- Windows 锁屏、休眠或系统进入暂停状态。

恢复后会重新安排一个完整间隔。主动文案会保留到下一条爱弥斯/Hermes 状态、用户反馈或错误提示替换它。

带问题的主动文案会出现“回应”按钮。点击后会展开聊天、保留原问题并聚焦输入框；首条回复会以一次性的 `proactive_reply` 上下文发送给 Hermes。取消、超时或忽略不会降低熟悉度，也不会再次催促。

### 3.3 动作与熟悉度

爱弥斯会组合招呼、探头、拖动着陆、思考、困倦、重连、庆祝和安静陪伴等连续动作。最近 4 个动作序列不会重复，同一序列播放时不会被普通微动作打断。

熟悉度是隐藏的、非惩罚式的阶段：初识（0–19）、熟悉（20–79）、默契（80+）。它只影响可选台词、动作组合和久别后的欢迎方式，不显示等级，不产生签到、饥饿、健康或失败状态。超过约 3 天未启动时最多显示一次“欢迎回来”类型的问候，不责备、不卖惨。

## 4. 设置说明

打开托盘“设置”，分为“外观”“桌宠”“Hermes”三个区域。外观调整会即时预览；桌宠设置通过“保存桌宠设置”写入。

### 4.1 外观

- **桌宠大小**：120–360 px。
- **紧凑/展开对话宽度与高度**：调整聊天窗口尺寸。
- **背景不透明度**：数值越低越透明。
- **文字大小**：80%–150%。

### 4.2 桌宠行为

- **动画速度**：50%–200%。
- **自动收缩等待**：5–180 秒。
- **始终置顶**：让窗口保持在其他普通窗口上方。
- **登录 Windows 时启动桌宠**：写入当前用户的启动项。
- **关闭窗口时隐藏到系统托盘**：开启后，窗口关闭按钮不会退出进程。
- **允许爱弥斯主动陪伴**：控制自动主动文案。
- **最长互动间隔**：5–240 分钟；实际间隔为该值的 60%–100%。
- **自动检测全屏应用并降低干扰**：识别全屏/游戏场景。
- **勿扰模式**：完全暂停主动互动。
- **安静时段**：支持跨午夜设置，例如 23 点到 8 点。
- **Hermes 官方更新**：每天最多检查一次，安装仍需确认。
- **Ameath 应用更新**：检查桌宠安装包，下载和安装仍需确认。
- **允许 Hermes 生成安全提示**：记忆提示开关，默认关闭，见第 5 节。
- **清除爱弥斯学习提示**：只清除桌宠的提示状态，不删除 Hermes 自身记忆。
- **减少动画**：保留静态待机、拖动反馈、聊天和错误状态，关闭大多数非必要动画。
- **低功耗模式**：`auto` 跟随系统，`on` 强制节能，`off` 不主动降帧。

锁屏、休眠、低功耗和高对比度行为会自动跟随系统能力；显示器或 DPI 改变后，窗口会重新限制到可见区域。

### 4.3 Hermes 区域

共享模式只显示连接状态、桌宠偏好和“切换或重新检测 Hermes”。不要在爱弥斯里编辑共享 Hermes 的全局模型、人格或工具。

独立模式可查看当前模型和桌宠专属工具，并分别使用“检查更新”“更新 Hermes”。更新期间界面会忙碌，不能重复提交；失败会显示日志路径，当前可用版本会保留。

## 5. 安全记忆提示与隐私

记忆提示默认关闭。明确勾选并确认后，Hermes 只能生成短小的兴趣、目标或近期话题提示：

- 不读取屏幕、前台窗口标题、文件内容、日历、浏览器或原始记忆；
- 原始 Hermes 记忆不会传给桌宠；
- 桌宠只接受包含 `request_id`、短文本、允许类别和过期时间的安全结果；
- 最多每 6 小时请求一次；本地只保存哈希和过期时间，不保存提示原文；
- 关闭开关或点击“清除爱弥斯学习提示”不会删除 Hermes 本身的长期记忆。

凭据和用户数据保存在当前 Windows 用户的数据目录，不会随角色文案发送。诊断导出完全在本机完成，不上传匿名崩溃报告。

## 6. Hermes 更新与应用更新

### 6.1 Hermes 更新

爱弥斯的 Hermes 更新与爱弥斯应用更新是两条独立流程。

- **共享 Hermes**：只对当前选择的官方本机仓库执行官方 `hermes update --yes --branch main`。工作区有未提交修改、远端不是官方仓库或身份无法验证时会拒绝更新。共享 Gateway 下的其他渠道和任务可能被重启；实验分支和提交仍保留，但更新会提示切换到官方 `main`。
- **内置 Hermes**：从官方 `main` 获取新提交，在 `%LOCALAPPDATA%\Ameath\runtimes\<commit>`（或自定义数据目录）建立独立槽，验证 CLI、插件和 Gateway 后原子切换。失败会自动回滚，不会更新 `D:\hermes\hermes-agent`，也不会停止共享 Hermes。

后台检查在 Gateway 就绪且空闲后开始，之后最多每 24 小时一次。离线失败不弹窗，约 6 小时后或下次启动重试；同一提交只提醒一次。更新开始后不要强行结束爱弥斯，完成或回滚后再退出。

### 6.2 爱弥斯应用更新

应用更新只跟踪官方仓库 [NingYan678/ameath-desktop](https://github.com/NingYan678/ameath-desktop) 的正式 GitHub Release：

- 启动稳定约 90 秒后首次检查，之后最多每天一次；离线失败约 6 小时后重试；
- 忽略草稿、预发布、降级版本和非 SemVer 标签；
- 只接受精确命名的安装包与 `.sha256` 文件，下载上限 512 MB；
- 只允许 HTTPS GitHub 资产域，使用临时 `.part` 文件和原子改名；
- SHA-256 不匹配、重定向异常或版本不一致时拒绝安装；
- 发现更新只提示，下载、退出和启动安装器都需要用户确认；Hermes 更新、授权、回复或确认进行中会延期。

爱弥斯应用本身没有静默自动升级。若 Windows 显示未知发布者，请同时核对 Release 页面和 SHA-256。

## 7. 数据、备份与卸载

### 7.1 数据位置

正式安装默认使用 `%LOCALAPPDATA%\Ameath`；开发运行可用环境变量 `AMEATH_DATA_HOME` 指定目录。常见文件包括：

| 文件/目录 | 内容 |
| --- | --- |
| `ui_settings.json` | 外观、桌宠行为和更新偏好。 |
| `pet_state.json` | 熟悉度、心情、精力、互动日期和已解锁动作。 |
| `hermes_update_state.json` | Hermes 检查时间、提交和错误摘要。 |
| `app_update_state.json` | 应用更新检查与提示状态。 |
| `companion_cue_state.json` | 记忆提示哈希和过期时间。 |
| `hermes/`、`runtimes/` | 内置 Hermes 数据与已验证运行时槽。 |
| `logs/` | 运行、更新和诊断日志。 |

升级或重装前建议关闭爱弥斯，备份整个 `%LOCALAPPDATA%\Ameath`。DPAPI 凭据绑定 Windows 用户和系统环境，不要把凭据文件直接复制给其他账户。

### 7.2 卸载

卸载器会询问是否删除个人数据：

- 选择保留：设置、熟悉度、记忆提示状态、凭据和 Hermes 更新槽继续保留，便于重新安装；
- 选择删除：删除爱弥斯用户数据。若以后还要恢复，请先手动备份。

## 8. 故障排查

### 爱弥斯没有自动说话

1. 确认托盘菜单显示“主动互动：已开启”。
2. 检查是否处于勿扰、安静时段、游戏/全屏、展开聊天、拖动、锁屏或休眠状态。
3. 默认要等待约 3–5 分钟；可以用托盘“让爱弥斯说句话”做一次手动测试。
4. 若 Hermes 未连接，点击“重新连接 Hermes”，并查看 `logs` 下的 `runtime.log`。

### 出现“Gateway 进程身份不匹配，已安全断开”

这是安全保护，表示发现的进程 PID、源码路径或运行描述文件不属于当前爱弥斯实例。请关闭重复的 Gateway，回到设置重新选择/检测 Hermes，再使用“重新连接 Hermes”。不要手动结束不确定的系统进程。

### Hermes 更新失败（退出码 1 或 2）

打开提示中的日志路径，通常位于 `%LOCALAPPDATA%\Ameath\logs\hermes-update-*.log`。重点检查：

- 共享仓库是否有未提交修改；
- 是否为官方远端和 `main`；
- Python/虚拟环境是否完整；
- 是否有另一个更新或 Gateway 正在占用文件；
- 网络是否能访问官方仓库。

不要使用 `--force` 或 `--force-venv` 绕过保护。共享更新失败不会覆盖本地实验修改；内置更新失败会保留旧槽并回滚。

### PowerShell 命令提示“找不到路径”或参数错误

`cd /d` 是 CMD 语法。在 PowerShell 中使用：

```powershell
Set-Location 'E:\digital pet'
& '.\.venv\Scripts\python.exe' -m pytest -q
```

执行带引号的程序时，前面需要 `&` 调用运算符。正式安装不需要手动运行 Python。

### 启动时出现黑色命令窗口

开发目录的 `run.bat` 会通过 `wscript` 后台启动 `pythonw`；如果直接运行 Python、调试启动器或使用旧快捷方式，可能看到控制台。正式安装包使用窗口模式运行。托盘图标缺失时先确认程序使用了完整安装包和正式资源目录，再重新安装并检查 Windows 托盘区域设置。

### 需要提交诊断信息

从托盘选择“导出诊断包”，只在本机生成压缩包。分享前请自行确认内容；日志会脱敏令牌、Bearer、密码、查询参数和本地路径，但不应把个人对话或业务信息上传到公开位置。

## 9. 术语表

| 术语 | 用大白话解释 |
| --- | --- |
| Hermes | 爱弥斯背后的 AI 引擎，负责理解消息、生成回答和管理工具。 |
| Gateway | Hermes 的后台服务。爱弥斯通过它发送消息，不直接承担模型推理。 |
| 共享模式 | 使用电脑上已有的 Hermes；其他 Hermes 渠道和任务可能与它共用 Gateway。 |
| 内置模式 | 爱弥斯单独维护的一份 Hermes，不改动电脑上的其他 Hermes。 |
| 模型服务 | 提供 AI 模型回答的服务，例如 DeepSeek、OpenAI 或 Ollama。 |
| 模型名 | 你要使用的具体模型标识，必须按服务商提供的名称填写。 |
| API Key | 云模型服务的访问凭证，类似密码；不要公开或发给他人。 |
| 服务地址 | 模型服务的接口网址；云服务从其 API 文档获取，本地 Ollama 通常是本机地址。 |
| 插件 | 让 Hermes 认识爱弥斯桌宠界面的连接组件，不等于浏览器插件。 |
| 运行时槽 | 内置 Hermes 每个版本独立存放的目录，更新失败时可回退旧版本。 |

## 10. 开发者附录

### 9.1 本地运行

项目面向 Windows 10/11 x64，开发环境使用 Python 3.12。推荐：

```powershell
Set-Location 'E:\digital pet'
& '.\.venv\Scripts\python.exe' -m digital_pet
```

也可以执行 `run.bat`。首次创建环境时，启动脚本会使用 `uv` 安装依赖；不建议把 `.venv` 或用户数据提交到 Git。

### 9.2 测试与静态检查

```powershell
& '.\.venv\Scripts\python.exe' -m pytest -q
& '.\.venv\Scripts\python.exe' -m ruff check src tests packaging hermes_platform
& '.\.venv\Scripts\python.exe' -m compileall -q src tests packaging hermes_platform
& '.\.venv\Scripts\python.exe' -m pip check
```

若路径不在 `E:\digital pet`，请把命令中的工作目录和相对路径替换为实际路径。
